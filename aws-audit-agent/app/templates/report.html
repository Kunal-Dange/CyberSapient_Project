METHODOLOGY AND LIMITATIONS

Read before relying on this report

  • Security Hub standards are listed per region as returned by AWS. The scanner does not silently enable or modify standards during an audit.
  • The built-in score is PASS ÷ (PASS + FAIL) for this application's checks. UNKNOWN and NOT APPLICABLE are excluded; this may not be compared directly to AWS Security Hub's score.
  • Coverage depends on enabled regions, configured Security Hub standards, IAM permissions, service APIs, and implemented collectors. Missing data is not evidence of compliance.
  • Framework labels are references, not proof of certification. Validate benchmark versions, exceptions, and business context with your security team.
  • Review all collection errors and unknown results. This report is not a penetration test, legal opinion, or substitute for production security review.
